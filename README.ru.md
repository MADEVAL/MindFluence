> **Убеждение, построенное на психологии, а не на манипуляции.**

AI-навык (промпт) v2.3, превращающий 20 когнитивных искажений в маркетинговый копирайтинг с высокой конверсией - для любого языка, любой платформы, любой аудитории. **v2.3: самодостаточное ядро с нарративной глубиной и проверкой происхождения данных.** Все таблицы, 13 анти-паттернов с правилами обнаружения, культурные данные и few-shot примеры встроены в SKILL.md. Обязательный PROVENANCE / TRUTH GATE не даёт выдумывать числа, имена и источники. Нарративная глубина поддерживает два режима: NPSA на реальных данных или явно помеченный `[illustrative]` fallback. Для базовой работы внешние файлы не требуются.

---

## Что это?

**MindFluence** - это системный промпт (навык) для LLM - GPT, Claude, Gemini, DeepSeek или любой другой способной модели. Он превращает AI в маркетингового стратега, который понимает, *почему* люди кликают, читают и покупают, а не просто *что* писать.

В основе - десятилетия исследований в области поведенческой экономики и эволюционной психологии: две системы Канемана, принципы Чалдини, психологические ловушки Мангера, когнитивный диссонанс Фестингера - сведённые в практические инструкции по копирайтингу.

## Как это работает

1. **Загрузите `SKILL.md`** как системный промпт в любую LLM. Файл самодостаточен для базовой работы.
2. **Дайте задание:** «Напиши пост в LinkedIn о...» / «Создай лендинг для...» / «Проведи аудит объявления».
3. **Получите результат** с каждым искажением под меткой, каждым решением с объяснением, каждым словом с психологическим обоснованием.

**LLM использует Bias Selection Router** - единую таблицу (38 строк, аудитория × продукт × платформа → мгновенный стек искажений) вместо 10-шаговой процедуры. После генерации запускается **механическая пост-генерационная верификация** - 7 проверок (цифры, имена, выход из страха, объяснение дефицита, вина на системе, человеческий нарратив, происхождение данных) - и обязательная **нарративная глубина**: NPSA на реальных данных или помеченный `[illustrative]` fallback.

**Четыре режима:**
- **Quick Mode** (по умолчанию) - аудит происхождения данных → поиск в роутере → проверка сценария → проверка категорий → генерация → 7-пунктовая верификация. Быстро для пользователя, быстро для LLM.
- **Deep Mode** - AI задаёт 5 уточняющих вопросов одновременно, затем маршрутизирует через тот же роутер.
- **Audit Mode** - анализирует существующий текст, используя механические правила обнаружения анти-паттернов (13 анти-паттернов, включая Statistical-Only Fallacy).
- **Optimize Mode** - итеративно улучшает копирайтинг на основе метрик с маппингом воронка→искажение и A/B-вариантами со статистическими порогами. Также выполняет качественный рерайт без метрик: смена тона, инъекция/удаление искажений, исправление анти-паттернов, адаптация под аудиторию/платформу (7 сценариев рерайта).

## Переключатель стиля (Tone-of-Voice)

Каждый результат помечается одним из 7 стилей (или гибридом с формулой: 70% основной ритм + 30% лексические маркеры вторичного стиля). Каждый тон имеет обязательный нарративный минимум - например, warm-human требует Named Person Story Arc или помеченный `[illustrative]` нарратив в первых 3 предложениях; luxe-minimal требует сенсорно-физический якорь.

| Стиль | Голос | Лучше всего для |
|--------|-------|------------------|
| `bold-sell` | Прямой, срочный, энергичный | Флеш-распродажи, DTC, запуски |
| `expert-calm` | Размеренный, аналитический, с данными | B2B, SaaS, консалтинг |
| `rebel-edgy` | Контринтуитивный, дерзкий | Молодёжные бренды, челленджеры |
| `warm-human` | Эмпатичный, сюжетный, уязвимый | Здоровье, коучинг, сообщества |
| `luxe-minimal` | Лаконичный, отточенный, высокий статус | Премиум, люкс, дизайн |
| `community-build` | Инклюзивный, племенной, «мы»-язык | Запуск сообществ, членство |
| `data-vivid` | На цифрах, визуальный, конкретный | Кейсы, ROI-страницы, B2B-презентации |

## Bias Selection Router

Навык не угадывает, какие искажения использовать. `SKILL.md` содержит встроенный **Bias Selection Router** - единую таблицу (38 строк), которая сопоставляет аудиторию × продукт × платформу напрямую со стеком искажений за один поиск. Три шага: lookup в роутере → scenario override → category check.

- **Температура аудитории** (холодная / тёплая / горячая / ушедшая / скептичная / stranger / defensive) ×
- **Тип продукта** (low-B2C, mid-B2C, high-B2C, B2B SaaS, инфопродукты, здоровье, сообщество) ×
- **Платформа** (Twitter/X, LinkedIn, Instagram, TikTok, email, лендинг, вебинар, search ads)
- **= Мгновенный стек искажений** (3–5 biases, предварительно проверенных на совместимость)
- **Scenario Override** - если запрос пользователя содержит триггер (например, «launch», «apology»), искажения заменяются согласно таблице Scenario Quick-Reference.

Также включает **Bias Conflict Detector** - 6 известных конфликтов искажений со стратегиями разрешения (например, Страх потери + Подтверждение конфликтуют → последовательность: Страх сначала, Подтверждение после раскрытия решения).

## Антипаттерны (с механическими правилами обнаружения)

`SKILL.md` содержит 13 встроенных антипаттернов - каждый с **правилом обнаружения**, которое LLM выполняет механически (grep-стиль) над своим выводом перед отправкой:

| # | Антипаттерн | Правило обнаружения | Пример провала |
|---|-------------|---------------------|-----------------|
| 1 | Размытое соцдоказательство | Поиск «тысячи», «многие» рядом с утверждениями о клиентах → FAIL | «Тысячи довольных клиентов» |
| 2 | Страх без выхода | Язык страха без решения в том же абзаце → FAIL | Угроза без немедленного решения |
| 3 | Фрейминг без якоря | «Не X, а Y» без количественной оценки старого способа → FAIL | «Это революция» - без точки отсчёта |
| 4 | Авторитет без доказательств | «Исследования показывают» без источника+года → FAIL | «Исследования показывают...» - без источника, без года |
| 5 | Транзакционная взаимность | Бесплатная ценность + предложение в одной коммуникации → FAIL | «Бесплатная книга! Теперь купи.» |
| 6 | Фальшивый дефицит | «Осталось X» без объяснения ПОЧЕМУ → FAIL | Таймеры, сбрасывающиеся при перезагрузке |
| 7 | Преждевременные невозвратные затраты | «Вы уже столько прошли» при первом контакте → FAIL | Язык невозвратных затрат в первом абзаце |
| 8 | Пустая «своя группа» | «Единомышленники» без названной идентичности → FAIL | «Люди как вы» - без общей идентичности |
| 9 | Ореол не того источника | «О нас писали в [издание]» которое аудитория не уважает → FAIL | «О нас писали в Forbes» - аудитория не уважает Forbes |
| 10 | Оскорбительное подтверждение | «Большинство ошибается» → читатель в «неправильной» группе → FAIL | Вызывает защитную реакцию, а не вовлечение |
| 11 | Абстрактная доступность | «Представьте [сценарий]» с <3 конкретными сенсорными деталями → FAIL | Нет запахов, звуков, времени, имён |
| 12 | Обвинительный диссонанс | «Вы говорите X, но делаете Y» → обвиняет читателя, а не систему → FAIL | Стыд → уход, а не действие |
| 13 | Statistical-Only Fallacy | Все social proof / authority claims - агрегатная статистика без named-person нарратива → FAIL | Информирует System 2, но не активирует System 1. Данные без истории = обработано, но не прочувствовано. |

**Пост-генерационная верификация:** После написания LLM выполняет обязательный 7-пунктовый механический чек-лист перед отправкой любого вывода - проверка конкретных чисел, названных источников, выходов из страха, объяснений дефицита, вины на системе, человеческой нарративной глубины (NPSA или `[illustrative]`) и **происхождения данных** (каждый факт прослеживается до ввода, проверенного источника или явного placeholder).

## Этические границы

**Всегда:**
- Используйте искажения, чтобы привлечь внимание к действительно ценным продуктам
- Будьте прозрачны о том, что ваш продукт делает, а что нет
- Используйте фактические, проверяемые социальные доказательства

**Никогда:**
- Не создавайте ложный дефицит
- Не фабрикуйте отзывы, обзоры, числа, имена, цитаты или источники
- Не эксплуатируйте страх для продажи решений, которые не решают проблему страха
- Не укрепляйте вредные убеждения
- Не нацеливайтесь на уязвимые группы населения

**Грань:** Выбрал бы клиент ваш продукт, обладая полной информацией и временем на размышление? *Да* = убеждение. *Нет* = манипуляция.

## Интеграция

MindFluence спроектирован для двусторонней интеграции с [RankWise](https://github.com/MADEVAL/RankWise) (SEO Content Engine) и [HumanAI](https://github.com/MADEVAL/HumanAI) (Text Humanization Engine). Три навыка формируют полный конвейер продакшена: SEO-структура → убедительный текст → человеческий голос.

### С RankWise (SEO Content Engine)

**Конвейер:** RankWise предоставляет SEO-скелет → MindFluence вставляет в него убеждение на основе когнитивных искажений.

**Что делает MindFluence:**
- Использует структуру заголовков брифа (H1, H2, H3) как скелет - не перестраивает
- Размещает основной ключ в: H1, первый абзац и минимум один H2 (как указано в брифе)
- Держит плотность ключевых слов в пределах тонального лимита (см. таблицу ниже)
- Сохраняет план внутренних ссылок брифа (целевые URL и предлагаемый анкор-текст)
- Перекрёстно проверяет power words - избегает слов, пересекающихся со списками AI-выжженных слов

**Лимиты плотности ключевых слов по тону:**

| Тон MindFluence | Макс. плотность | Примечания |
|-----------------|-----------------|------------|
| `bold-sell` | 1.5% | Самый высокий риск переспама. Строгий лимит. |
| `expert-calm` | 1.2% | Естественно подходит для информационного контента. |
| `warm-human` | 1.2% | Разговорный тон хорошо распределяет ключевые слова. |
| `rebel-edgy` | 1.5% | Контринтуитивный фрейминг может вытолкнуть ключ - обеспечьте размещение в первых 150 словах. |
| `luxe-minimal` | 1.0% | Разреженный текст - разместите ключ один раз на видном месте вместо множественных повторений. |

**Совместные промпты:**
- «RankWise SEO brief for [topic]. Keyword: [kw]. Then MindFluence from that brief. Expert-calm tone.»
- «RankWise SEO brief for SaaS landing page. Then MindFluence landing page from that brief.»

### С HumanAI (Text Humanization)

**Конвейер:** MindFluence генерирует убедительный текст → HumanAI очеловечивает его, не ломая структуру искажений.

**Сопоставление тонов:**

| Тон MindFluence | Тон HumanAI |
|-----------------|-------------|
| `warm-human` | `human` |
| `expert-calm` | `expert` |
| `bold-sell` | `landing` |
| `rebel-edgy` | `social` |
| `luxe-minimal` | `expert` |

**Для сохранения структуры искажений при очеловечивании:** используйте `PIPELINE: cleanup → specificity → tone(skipped) → rhythm → proofread` - это говорит HumanAI пропустить Stage 3 (tone) и сохранить голос MindFluence.

**Совместные промпты:**
- «Generate MindFluence copy (bold-sell tone), then HumanAI humanize it. EN.»
- «MindFluence landing page for [product]. Then pass through HumanAI.»

### Совместимость Bias-SEO

Некоторые когнитивные искажения имеют специфические взаимодействия с SEO. См. `scenarios/seo-brief.md` для полной таблицы.

| Искажение | SEO-риск | Смягчение |
|-----------|----------|-----------|
| Якорение | Низкий | Числа в открытии удовлетворяют C5 (число в заголовке) |
| Страх потери | Низкий | «Перестаньте терять X» - убедитесь, что ключ появляется в первых 150 словах |
| Соцдоказательство | Средний | Отзывы не содержат ключей → добавьте ключ в обрамляющие предложения |
| Невозвратные затраты | Низкий | Фрейминг времени/усилий не конфликтует с SEO |
| Дефицит | Средний | «Ограничено», «Осталось X» может вытолкнуть ключ из первых 150 слов |
| Подтверждение | Низкий | «Вы и так знаете X» - хорошо ложится рядом с ключом |

### Тройной конвейер (RankWise → MindFluence → HumanAI)

Полный производственный конвейер:

1. **RankWise** выдаёт полный SEO-бриф с планом ключевых слов, структурой заголовков, мета-черновиками, планом внутренних ссылок и целевым количеством слов.
2. **MindFluence** генерирует убедительный текст внутри SEO-скелета, применяя когнитивные искажения секция за секцией.
3. **HumanAI** очеловечивает текст, соблюдая: без удаления заголовков с ключами, без удаления якорей внутренних ссылок, без очистки маркеров искажений (числа соцдоказательств, числа якорения), сохранение минимального количества слов.
4. **RankWise Audit** выполняет финальную верификацию 49 SEO-факторов.

**Совместный тройной промпт:**
```
Triple pipeline:
1) RankWise SEO brief for [topic]. Keyword: [kw]. Language: [xx].
2) MindFluence generate from that brief. Tone: [expert-calm/warm-human/bold-sell].
3) HumanAI humanize the MindFluence output. Preserve SEO structure + bias markers.
4) RankWise audit the final result.
```

## Быстрый старт

### Быстрый старт (любая LLM)

1. Скопируйте содержимое [`SKILL.md`](https://github.com/MADEVAL/MindFluence/blob/main/SKILL.md)
2. Вставьте как системный промпт / пользовательские инструкции
3. Напишите: *«Создай пост на тему [тема] для [аудитория] на [платформа]»*
4. Для углублённого контекста: LLM может скачать дополнительные файлы, используя GitHub URL-ы из секции EXTERNAL REFERENCE FILES в SKILL.md

### С OpenCode (нативно)

Поместите папку `mindfluence/` в `.opencode/skills/` (проект) или `~/.config/opencode/skills/` (глобально). OpenCode обнаруживает `SKILL.md` по пути - дополнительная настройка не требуется. Имя папки становится ID навыка; для переносимости держите его в lowercase kebab-case (`mindfluence`). Навык активируется при запросе маркетинговых текстов, рекламы, лендингов, писем или контента для запусков.

### С Claude Code

Скопируйте `SKILL.md` в ваш проект как `CLAUDE.md` или поместите всю папку `mindfluence/` в `~/.claude/skills/`.

### Как Custom GPT / Проект Claude

Загрузите `SKILL.md` как системный промпт. Для углублённого контекста добавьте `decision-matrix.md`, `anti-patterns.md`, `cultural-matrix.md` и файлы из `scenarios/` и `examples/` в knowledge section. Файл самодостаточен для базовой работы, но внешние файлы дают более богатую логику decision-matrix, детальные примеры анти-паттернов и полные сценарные плейбуки.

### С любым другим AI-агентом (Cursor, Windsurf, Copilot, Cline, Aider и др.)

Скопируйте содержимое `SKILL.md` в файл инструкций этого агента (`.cursorrules`, `.windsurfrules`, `.github/copilot-instructions.md`, `.clinerules`, `CONVENTIONS.md` и т.д.). Содержимое промпта не зависит от платформы - меняется только имя файла.

## Требования

- Любая способная LLM с полем системного промпта (GPT, Claude, Gemini, DeepSeek, open-source модели)
- **Самодостаточное ядро:** `SKILL.md`. Все таблицы, правила обнаружения, культурные данные и примеры для стандартных задач встроены.
- Контекстное окно: 32K минимум для COMPACT/STANDARD; 64K+ рекомендуется для EXTENDED и внешних файлов.
- Для углублённого контекста: внешние файлы (`decision-matrix.md`, `anti-patterns.md`, `cultural-matrix.md`, `scenarios/`) сохранены в репозитории - полные GitHub URL-ы в секции EXTERNAL REFERENCE FILES файла SKILL.md, так что LLM, работающие с одним файлом, могут направить пользователя к их скачиванию
- Без API-ключей, без инструментов, без зависимостей - чистый промпт-инжиниринг
- Работает на любом языке; адаптирует культурные отсылки под целевой рынок

## Почему «mindfluence»?

**mind** (мозг - здесь живут когнитивные искажения) + **influence** (то, что убеждение на самом деле делает - формирует решения без принуждения).
